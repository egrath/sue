User requests:

Agent analysis / thoughts:
- ~3,240 LOC: sue.c (main/globals), data.c (gap-buffer primitives),
  display.c (curses rendering), funcs.c (commands), command.c (input dispatch),
  sue.h (shared decls). Editor stores text in a gap buffer; block markers and
  cursor jump the gap via text_move().
- Measured warnings (cc -std=c89 -Wpedantic -Wall, macOS clang):
  488x -Wstrict-prototypes (K&R prototypes in sue.h + all ~83 definitions),
  201x -Wdeprecated-non-prototype (consequence of missing prototypes),
  5x -Wc99-extensions (trailing comma after ONSCREEN in enum helptype),
  4x -Wunused-variable (eargv, i in sue.c; retcode in display.c; c in funcs.c),
  1x -Wimplicit-int (main without return type), 1x tempnam deprecation.
- Hidden dangers beyond -Wall:
  * ~12 call sites pass fewer args than the declared params of
    prompt/statprint/status/xwprintw (legal under K&R, compile errors once
    prototypes exist). Located all of them.
  * signal(SIGALRM, quickhlp) passes void(*)(void) where void(*)(int) is
    required -> needs trampolines.
  * WINDOW *editwin/... were tentative definitions in the header -> breaks
    with -fno-common (modern default).
  * status() used a char loop counter over COLS -> UB on >127-col terminals;
    same class in disp_page() (char row counter over editlines).
  * sabort(): tempnam() deprecated; strcat(homeptr, "/SUEsaved") wrote into
    the HOME environment string (environ overflow).

Decisions (user confirmed via questions):
- Fix the latent bugs too (status/disp_page overflow, strcat-HOME, tempnam).
- Fix helper call sites with NULL fillers; do NOT rewrite with <stdarg.h>.
- Add -Werror to the Makefile after the build is clean.
- Make single-file helpers static (test, dsp_lne, disp_page, status_linecol,
  doalloc) and drop them from sue.h.
