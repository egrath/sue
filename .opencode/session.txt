Agent analysis / thoughts:

    with -fno-common (modern default).
  * status() used a char loop counter over COLS -> UB on >127-col terminals;
    same class in disp_page() (char row counter over editlines).
  * sabort(): tempnam() deprecated; strcat(homeptr, "/SUEsaved") wrote into
    the HOME environment string (environ overflow).

- Fix the latent bugs too (status/disp_page overflow, strcat-HOME, tempnam).
- Fix helper call sites with NULL fillers; do NOT rewrite with <stdarg.h>.
- Add -Werror to the Makefile after the build is clean.
- Make single-file helpers static (test, dsp_lne, disp_page, status_linecol,

behaves like the auto-indented RETURN, keeping the WordStar split-at-
cursor semantics (option (B), "insert an empty line before the
cursor line", would have changed the mid-line behavior fundamentally;
the old doc block wrongly claimed (B) anyway while the 1995 code did
the split).

Refactor: the RETURN case's split logic extracted into the shared
int split_line (int keep_cursor) (funcs.c, documented): the scan,
the all-or-nothing gap-space check, the newline, the indent copy
(the gap-jumping walk), the bounded trim, txt_x++/txt_y = column
(gap_end), mod = TRUE. keep_cursor = 0: RETURN (disp_mode = dinsln
set by the caller). keep_cursor = 1: the cursor returns to the
split point - the gap steps back over the indent + the newline
(the standard byte-shift idiom, the logical text unchanged),
txt_x--, txt_y = the saved old column; disp_mode = dpage (the
